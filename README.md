# MCUXpresso SDK : mcux-sdk-middleware-edgefast-bluetooth

## Overview

This repository is for MCUXpresso SDK EdgeFast Bluetooth middleware delivery and it contains EdgeFast Bluetooth components officially provided in NXP MCUXpresso SDK. This repository is part of the MCUXpresso SDK overall delivery which is composed of several sub-repositories/projects. Navigate to the top/parent repository [mcuxsdk](https://github.com/nxp-mcuxpresso/mcuxsdk-manifests/) for the complete delivery of MCUXpresso SDK to be able to build and run EdgeFast Bluetooth examples that are based on mcux-sdk-middleware-edgefast-bluetooth components.

## Documentation

Overall details can be reviewed here: [MCUXpresso SDK Online Documentation](https://mcuxpresso.nxp.com/mcuxsdk/latest/html/introduction/README.html)

Visit [EdgeFast Bluetooth - Documentation](https://mcuxpresso.nxp.com/mcuxsdk/latest/html/middleware/edgefast_bluetooth/docs/index.html) to review details on the contents in this sub-repo.

Instructions on how to install the MCUXpresso SDK provided from GitHub via west manifest [Getting Started with SDK - Detailed Installation Instructions](https://mcuxpresso.nxp.com/mcuxsdk/latest/html/gsd/installation.html#installation)
